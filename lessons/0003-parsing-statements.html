Expressions vs. Statements

Everything you've built so far — the full precedence chain from Lesson 1 — handles expressions: things that produce a value. 1 + 2, foo(x), a ? b : c are all expressions.

Statements are different. They do something — declare a variable, call a function and throw away the result, loop, branch. Most statements contain expressions, but are not themselves expressions.

The Key Difference
Expressions are dispatched by content — any token could start an expression, so you try rules in precedence order. Statements are dispatched by leading keyword — peek() immediately tells you which statement you're parsing. This is what makes the statement parser a simple switch.

The Statement Grammar

Here's the full statement grammar for plex, derived from your tokenizer's keywords:

program ::= statement* EOF
statement ::= importStmt
             | varDecl
             | ifStmt
             | whileStmt
             | fnDecl
             | structDecl
             | exprStmt

exprStmt ::= expression ";"
importStmt ::= "import" IDENT "from" STRING ";"
varDecl ::= "mut"? IDENT ":" typeExpr "=" expression ";"
ifStmt ::= "if" "(" expression ")" block ( "else" ( ifStmt | block ) )?
whileStmt ::= "while" "(" expression ")" block
block ::= "{" statement* "}"
fnDecl ::= "fn" IDENT "(" params? ")" ( ":" typeExpr )? block
params ::= param ( "," param )*
param ::= "mut"? IDENT ":" typeExpr
structDecl ::= "struct" IDENT "{" param* "}"
typeExpr ::= IDENT ( "[" "]" )?

The Dispatch Table

parseStatement is a switch on the leading token. Every branch delegates to a dedicated parse function:

Leading tokenCallsProduces
"import"parseImportStmt()ImportStatement
"mut" | IDENT + ":"parseVarDecl()VariableDeclaration
"if"parseIfStmt()IfStatement
"while"parseWhileStmt()WhileStatement
"fn"parseFnDecl()FunctionDeclaration
"struct"parseStructDecl()StructDeclaration
anything elseparseExpression() + ";"ExpressionStatement

The Program Loop

The root of the parser is now a loop — not a single expression call. Parse() becomes:

func (p *Parser) Parse() (*Program, error) {
    program := &Program{}

    for p.peek().IsToken() != TokenType_EOF {
        stmt, err := p.parseStatement()
        if err != nil {
            return nil, err
        }
        program.Stmts = append(program.Stmts, stmt)
    }

    return program, nil
}

parseStatement: the Dispatcher

func (p *Parser) parseStatement() (AstNode, error) {
    t := p.peek().(*ValueToken)

    switch {
    case t.IsToken() == TokenType_Ident && t.Value == "import":
        return p.parseImportStmt()
    case t.IsToken() == TokenType_Ident && t.Value == "fn":
        return p.parseFnDecl()
    case t.IsToken() == TokenType_Ident && t.Value == "struct":
        return p.parseStructDecl()
    case t.IsToken() == TokenType_Ident && t.Value == "if":
        return p.parseIfStmt()
    case t.IsToken() == TokenType_Ident && t.Value == "while":
        return p.parseWhileStmt()
    case isVarDeclStart(p):
        return p.parseVarDecl()
    default:
        return p.parseExprStmt()
    }
}
Keywords are TokenType_Ident in your tokenizer
Looking at your tokenizer, keywords like "if", "fn", "while" are emitted as TokenType_Ident with a Value field — not a distinct TokenType_Keyword. So the switch has to check both the type and the value. Consider adding a TokenType_Keyword type and emitting keywords with it — that would let you use a cleaner switch t.IsToken(). But it works either way.

Three Statements to Implement

The patterns repeat. Here are the three most instructive ones:

parseIfStmt — branching + else chaining

// ifStmt ::= "if" "(" expression ")" block ( "else" ( ifStmt | block ) )?
func (p *Parser) parseIfStmt() (AstNode, error) {
    start, _ := p.advance().Range()    // consume "if"
    if _, err := p.expect(TokenType_BracketParamOpen); err != nil {
        return nil, err
    }
    condition, err := p.parseExpression()
    if err != nil { return nil, err }
    if _, err := p.expect(TokenType_BracketParamClose); err != nil {
        return nil, err
    }
    body, err := p.parseBlock()
    if err != nil { return nil, err }

    node := &IfStatement{Start: start, Condition: condition, Body: body}

    // optional else branch
    if next, ok := p.peek().(*ValueToken); ok && next.Value == "else" {
        p.advance() // consume "else"
        if isKeyword(p.peek(), "if") {
            node.Else, err = p.parseIfStmt() // else if — recurse!
        } else {
            node.Else, err = p.parseBlock()
        }
        if err != nil { return nil, err }
    }

    _, node.End = node.Body.Range()
    return node, nil
}
else if is just recursion
There's no special else if rule in the grammar. else is followed by either a block or another if statement — and parseIfStmt handles the latter by calling itself. This is how every language with else if works under the hood.

parseFnDecl — parameters + return type + body

// fnDecl ::= "fn" IDENT "(" params? ")" (":" typeExpr)? block
func (p *Parser) parseFnDecl() (AstNode, error) {
    start, _ := p.advance().Range()  // consume "fn"
    name, err := p.expect(TokenType_Ident)
    if err != nil { return nil, err }
    if _, err := p.expect(TokenType_BracketParamOpen); err != nil {
        return nil, err
    }

    params, err := p.parseParams()
    if err != nil { return nil, err }

    if _, err := p.expect(TokenType_BracketParamClose); err != nil {
        return nil, err
    }

    var returnType AstNode
    if p.peek().IsToken() == TokenType_Colon {
        p.advance() // consume ":"
        returnType, err = p.parseTypeExpr()
        if err != nil { return nil, err }
    }

    body, err := p.parseBlock()
    if err != nil { return nil, err }
    _, end := body.Range()

    return &FunctionDeclaration{
        Start:      start,
        End:        end,
        Name:       name.(*ValueToken).Value,
        Params:     params,
        ReturnType: returnType,
        Body:       body,
    }, nil
}

parseBlock — statements until "}"

// block ::= "{" statement* "}"
func (p *Parser) parseBlock() (*Block, error) {
    open, err := p.expect(TokenType_BracketCurlyOpen)
    if err != nil { return nil, err }
    start, _ := open.Range()

    stmts := []AstNode{}
    for p.peek().IsToken() != TokenType_BracketCulryClose &&
        p.peek().IsToken() != TokenType_EOF {
        stmt, err := p.parseStatement()
        if err != nil { return nil, err }
        stmts = append(stmts, stmt)
    }

    close, err := p.expect(TokenType_BracketCulryClose)
    if err != nil { return nil, err }
    _, end := close.Range()

    return &Block{Start: start, End: end, Stmts: stmts}, nil
}

Helper: isKeyword
You'll want a small helper used in several places: 
func isKeyword(t Token, value string) bool {
    vt, ok := t.(*ValueToken)
    return ok && vt.IsToken() == TokenType_Ident && vt.Value == value
}
