Lesson 31 – While Loops: block + loop + br

Goal: compile while cond { body }, break, and continue to valid WASM binary. By the end you can write sum(10) and get 55.

Files you'll touch: opcodes.go · body.go · end_to_end_test.go

The Big Idea: WASM Has No while Opcode

In x86 assembly a while loop is a conditional forward jump (skip the body) plus an unconditional backward jump (restart). WASM disallows arbitrary jumps — but it does allow structured backward edges via a two-level nesting:

02 40 ; block (empty blocktype) — the BREAK target 03 40 ; loop (empty blocktype) — the CONTINUE target ; ... emit condition ... 45 ; i32.eqz — negate: push 1 when condition was 0 (false) 0D 01 ; br_if 1 — if negated condition is 1, exit the outer block ; ... emit body ... 0C 00 ; br 0 — unconditional restart: jump to top of loop 0B ; end (loop) 0B ; end (block)
The crucial asymmetry: A block label points to its END — br into a block is a forward jump (skip to the closing end). A loop label points to its START — br into a loop is a backward jump (restart from the top). This is why br 0 inside a loop restarts the loop, not exits it.

Label Depth Arithmetic

WASM branch instructions take a relative depth index. Depth 0 is the innermost enclosing block/loop/if; depth 1 is the next one out; and so on.

From inside the while loop body, with no extra nesting:

depth=2 → block ; label index from inside loop body: 1 depth=2 → loop ; label index from inside loop body: 0 ; === loop body (no extra nesting) === break → br 1 ; exits block (forward to end) continue → br 0 ; restarts loop (backward to top) end end

But when break or continue appear inside an if block within the loop, an extra level is added:

block ; label: 1 from loop body, 2 from inside if loop ; label: 0 from loop body, 1 from inside if ; depth=2 here — no extra blocks open if 0x40 ; opens one more level ; depth=3 here — one extra block open break → br 2 ; +1 past the if, then exits block continue → br 1 ; +1 past the if, then restarts loop end br 0 ; unconditional back-edge end end

The implementation tracks a blockDepth counter on bodyEncoder, incremented whenever a block, loop, or if is opened and decremented on end. The loopStack records the blockDepth at the moment each loop's labels were created, so the correct depth can be computed at the point of any break or continue.

Implementation

Step 1 — Add opcodes

Open opcodes.go. Add to the constant block:

// Structured loops
OpBlock  byte = 0x02  // label points to END  — br exits forward
OpLoop   byte = 0x03  // label points to START — br restarts backward
OpBr     byte = 0x0C  // unconditional branch
OpBrIf   byte = 0x0D  // conditional branch (pops i32; branches if non-zero)
OpI32Eqz byte = 0x45  // i32.eqz: 0→1, anything else→0 (logical not)

Step 2 — Add depth tracking to bodyEncoder

Open body.go. Extend the struct:

type loopEntry struct {
    blockLabel uint32  // blockDepth when the block was opened (break target)
    loopLabel  uint32  // blockDepth when the loop was opened (continue target)
}

type bodyEncoder struct {
    buf        []byte
    locals     map[string]uint32
    localTypes []byte
    blockDepth int         // number of open block/loop/if instructions
    loopStack  []loopEntry // one entry per enclosing while loop
}

Step 3 — Track depth in the existing IfStatement case

The if instruction opens a new label level, so blockDepth must be updated there too — otherwise break/continue inside a conditional will emit wrong depths.

case *script.IfStatement:
    if err := b.walk(n.Condition); err != nil {
        return err
    }
    b.buf = append(b.buf, OpIf, BlockTypeEmpty)
    b.blockDepth++
    if err := b.walk(n.Body); err != nil {
        return err
    }
    if n.Else != nil {
        b.buf = append(b.buf, OpElse)
        if err := b.walk(n.Else); err != nil {
            return err
        }
    }
    b.buf = append(b.buf, OpEnd)
    b.blockDepth--
    return nil

Step 4 — Handle WhileStatement

Add this case to the walk switch. The pattern is: emit block, emit loop, record depths, emit negated condition + br_if, emit body, emit back-edge br, close both blocks.

case *script.WhileStatement:
    // outer block: break target (label points to END)
    b.buf = append(b.buf, OpBlock, BlockTypeEmpty)
    b.blockDepth++
    blockLabel := uint32(b.blockDepth)

    // inner loop: continue target (label points to START)
    b.buf = append(b.buf, OpLoop, BlockTypeEmpty)
    b.blockDepth++
    loopLabel := uint32(b.blockDepth)

    b.loopStack = append(b.loopStack, loopEntry{blockLabel: blockLabel, loopLabel: loopLabel})

    // condition — negate then branch-if to exit
    if err := b.walk(n.Condition); err != nil {
        return err
    }
    b.buf = append(b.buf, OpI32Eqz)
    b.buf = append(b.buf, OpBrIf)
    b.buf = AppendULEB128(b.buf, uint32(b.blockDepth)-blockLabel)

    // body
    if err := b.walk(n.Body); err != nil {
        return err
    }

    // unconditional back-edge to loop top
    b.buf = append(b.buf, OpBr)
    b.buf = AppendULEB128(b.buf, uint32(b.blockDepth)-loopLabel)

    b.loopStack = b.loopStack[:len(b.loopStack)-1]
    b.blockDepth -= 2
    b.buf = append(b.buf, OpEnd, OpEnd)
    return nil
Why emit OpEnd, OpEnd together? The first end closes the loop; the second closes the block. They're adjacent bytes with no instruction between them — valid because the br 0 back-edge above prevents fall-through reaching the first end at runtime.

Step 5 — Handle BreakStatement and ContinueStatement

break and continue are unconditional branches. The depth is computed from the stored label against the current blockDepth:

case *script.BreakStatement:
    if len(b.loopStack) == 0 {
        return fmt.Errorf("break outside loop")
    }
    entry := b.loopStack[len(b.loopStack)-1]
    b.buf = append(b.buf, OpBr)
    b.buf = AppendULEB128(b.buf, uint32(b.blockDepth)-entry.blockLabel)
    return nil

case *script.ContinueStatement:
    if len(b.loopStack) == 0 {
        return fmt.Errorf("continue outside loop")
    }
    entry := b.loopStack[len(b.loopStack)-1]
    b.buf = append(b.buf, OpBr)
    b.buf = AppendULEB128(b.buf, uint32(b.blockDepth)-entry.loopLabel)
    return nil

Step 6 — Extend collectLocals to recurse into while bodies

The two-phase local pre-scan needs to walk into while loop bodies so that let declarations inside loops get assigned indices before any bytecode is emitted. Add a case to collectLocals:

case *script.WhileStatement:
    b.collectLocals(n.Body)
case *script.IfStatement:
    b.collectLocals(n.Body)
    if n.Else != nil {
        b.collectLocals(n.Else)
    }
This is a real bug waiting to happen. Without this, a let x inside a while body won't appear in the locals vec, so local.get/local.set will emit an index that is out of bounds — wazero will reject the module at instantiation time with a validation error, not a runtime trap.

Step 7 — Write the test

Open end_to_end_test.go. A triangular sum exercises while, a local counter, and mutation:

func TestEndToEnd_WhileSum(t *testing.T) {
    src := `
        fn sum(n: i64): i64 {
            let i: i64 = 1;
            let acc: i64 = 0;
            while i <= n {
                acc = acc + i;
                i = i + 1;
            }
            return acc;
        }
    `
    runOne(t, src, "sum", []uint64{10}, 55)   // 1+2+…+10 = 55
    runOne(t, src, "sum", []uint64{0}, 0)    // zero iterations
    runOne(t, src, "sum", []uint64{1}, 1)    // exactly one iteration
}

Run with:

go test ./compiler/binary/... -run TestEndToEnd -v

Byte Trace for sum(3)

Walking through the compiled body for sum(3) helps confirm the encoding is right:

02 ; 2 local groups: (1 × i64) for i, (1 × i64) for acc 01 7E ; 1 × i64 (i) 01 7E ; 1 × i64 (acc) ; let i: i64 = 1 42 01 ; i64.const 1 21 01 ; local.set 1 (i is param-count + 0 = index 1, since n is index 0) ; let acc: i64 = 0 42 00 ; i64.const 0 21 02 ; local.set 2 (acc is index 2) 02 40 ; block (break target) 03 40 ; loop (continue target) ; while i <= n 20 01 ; local.get 1 (i) 20 00 ; local.get 0 (n) 57 ; i64.le_s → i32: 1 if i<=n, 0 if i>n 45 ; i32.eqz → 1 if i>n (condition false), 0 if i<=n 0D 01 ; br_if 1 → exit block if condition was false ; acc = acc + i 20 02 ; local.get 2 (acc) 20 01 ; local.get 1 (i) 7C ; i64.add 21 02 ; local.set 2 (acc) ; i = i + 1 20 01 ; local.get 1 (i) 42 01 ; i64.const 1 7C ; i64.add 21 01 ; local.set 1 (i) 0C 00 ; br 0 → restart loop 0B ; end (loop) 0B ; end (block) ; return acc 20 02 ; local.get 2 0F ; return 00 0B ; unreachable + end (function body)
