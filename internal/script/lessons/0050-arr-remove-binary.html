Lesson 50 – arr.remove in the Binary Backend

Previous: Lesson 49 – arr.append in the Binary Backend

This lesson has two parts. First, a warm-up bug-fix in the append implementation from lesson 49. Then the main event: implementing arr.remove(idx), which introduces a shift loop generated entirely in binary bytes — and forces you to think carefully about what WASM's loop labels mean when they live inside a built-in, not in user code.

Part 1 — Fix the Double-Walk Bug in append

The append case in body.go walks n.Args[0] twice: once before addSyntheticLocal and once at the correct position inside the instruction sequence.

Why didn't the tests catch it? The stray i64 pushed by the first walk ends up below the i32 ptr left by the append body. The Block-level OpDrop (emitted for every expression-as-statement) removes the top value — the i32 ptr. That leaves the stray i64 sitting below all subsequent values, including the return value. WASM's return is polymorphic: it takes the topmost return-count values and discards everything below. The validator never sees a problem. The tests produce the right answers by accident.
Fix — one deletion

In body.go, inside the "append" case, delete the premature first walk of n.Args[0]:

Lesson: A test suite that passes despite a latent bug is more dangerous than a failing one — it gives false confidence. The mask here was WASM's polymorphic validation. This pattern (masked by a consuming Drop + polymorphic return) can hide double-walks whenever the stray type happens to cancel with a surrounding Drop.

Part 2 — Implementing arr.remove

arr.remove(idx) removes the element at idx, shifts all elements after it one position to the left, decrements the length, and returns the removed element. Unlike append, it is an expression with a value.

Memory Layout After a Remove

Before: int[] = [10, 20, 30] at ptr:

ptr+0 [ len: 3 ] ptr+4 [ 10 : i64 ] ← idx 0 ptr+12 [ 20 : i64 ] ← idx 1 (being removed) ptr+20 [ 30 : i64 ] ← idx 2

After arr.remove(1):

ptr+0 [ len: 2 ] ptr+4 [ 10 : i64 ] ← idx 0 (unchanged) ptr+12 [ 30 : i64 ] ← idx 1 (shifted left from idx 2) ptr+20 [ stale ] ← length field says 2, so this slot is invisible

The shift loop walks cur from idx to new_len - 1, copying element cur+1 into slot cur each iteration.

Five Synthetic Locals

remove needs scratch space for five values that must survive across multiple instruction sequences:

LocalWASM typeHolds
arri32array pointer
idxi32removal index (unwrapped from i64)
retelement valtypethe removed element (return value)
leni32old_len − 1 = new_len
curi32shift cursor, starts at idx

All of these follow the addSyntheticLocal pattern from lesson 49. The only new wrinkle: ret takes type valType(objType.Element) rather than ValI32, because the removed element might be i64 or f64.

The Internal Shift Loop

The shift loop is a block + loop pair emitted entirely in binary bytes. It is structurally identical to a while loop — but it must not be added to b.loopStack.

Why not loopStack? loopStack tracks loops that user code can reach with break and continue. The shift loop is an internal compiler artifact — if a break branched into it, it would corrupt the shift and leave the array half-modified. The loop must be invisible to user control flow.

Because the loop is not on loopStack, you must compute branch depths directly from b.blockDepth. This is the same arithmetic the while-loop encoder uses — you just don't expose the labels to break/continue.

blockDepth must be maintained

Even though the shift loop is invisible to user code, it still must properly increment and decrement b.blockDepth. If a user-visible while loop contains a remove call, the outer loop's break/continue computes its branch depth as b.blockDepth − entry.blockLabel. An unbalanced internal blockDepth would produce wrong relative depths and broken branch targets.

Branch depth arithmetic for the internal loop

Entering the shift loop from outside (current blockDepth = D):

emit OpBlock → b.blockDepth++ → D+1 ← blockMark = D+1 emit OpLoop → b.blockDepth++ → D+2 ← loopMark = D+2 inside loop (blockDepth = D+2): br_if exit: depth − blockMark = D+2 − (D+1) = 1 br continue: depth − loopMark = D+2 − (D+2) = 0 emit OpEnd (loop) → b.blockDepth-- → D+1 emit OpEnd (block) → b.blockDepth-- → D

Full Instruction Sequence

// 1 — allocate 5 synthetic locals
arrLocal := b.addSyntheticLocal(ValI32)
idxLocal := b.addSyntheticLocal(ValI32)
retLocal := b.addSyntheticLocal(valType(objType.Element))
lenLocal := b.addSyntheticLocal(ValI32)
curLocal := b.addSyntheticLocal(ValI32)

// 2 — save array pointer
walk(callee.Object)   → [ptr:i32]
local.set $arr        → []

// 3 — save index (source integers arrive as i64)
walk(n.Args[0])       → [idx:i64]
i32.wrap_i64          → [idx:i32]
local.set $idx        → []

// 4 — save the element to return: arr + 4 + idx*eSize
local.get $arr
i32.const 4
i32.add
local.get $idx
i32.const <eSize>
i32.mul
i32.add               → [elem_addr:i32]
<loadOp>              → [elem:elemType]
local.set $ret        → []

// 5 — new_len = old_len - 1
local.get $arr
i32.load align=2
i32.const 1
i32.sub               → [new_len:i32]
local.set $len        → []

// 6 — cursor starts at idx
local.get $idx
local.set $cur

// 7 — internal shift loop
block []              ← blockDepth++, blockMark = blockDepth
loop  []              ← blockDepth++, loopMark  = blockDepth

  exit check: cur >= len → break to outer block
  local.get $cur
  local.get $len
  i32.ge_s
  br_if (blockDepth−blockMark)

  dst addr: arr + 4 + cur*eSize
  local.get $arr
  i32.const 4
  i32.add
  local.get $cur
  i32.const <eSize>
  i32.mul
  i32.add

  src value: arr[(cur+1)] = arr + 4 + (cur+1)*eSize
  local.get $arr
  i32.const 4
  i32.add
  local.get $cur
  i32.const 1
  i32.add
  i32.const <eSize>
  i32.mul
  i32.add
  <loadOp>

  store dst ← src
  <storeOp>

  cur++
  local.get $cur
  i32.const 1
  i32.add
  local.set $cur

  br (blockDepth−loopMark)   ← continue loop

end   ← end loop  (blockDepth--)
end   ← end block (blockDepth--)

// 8 — write new length back to arr
local.get $arr
local.get $len
i32.store align=2

// 9 — leave removed element on stack as return value
local.get $ret        → [elem:elemType]

case "remove":
    if len(n.Args) != 1 {
        return fmt.Errorf("remove method was expecting 1 arg but was given %d", len(n.Args))
    }
    eKind    := objType.Element.Kind
    eSize    := elemSizeOf(eKind)
    loadOp, loadAlign := loadOpcode(eKind)
    stOp, stAlign     := storeOpcode(eKind)

    arrLocal := b.addSyntheticLocal(ValI32)
    idxLocal := b.addSyntheticLocal(ValI32)
    retLocal := b.addSyntheticLocal(valType(objType.Element))
    lenLocal := b.addSyntheticLocal(ValI32)
    curLocal := b.addSyntheticLocal(ValI32)

    // save arr
    if err := b.walk(callee.Object); err != nil { return err }
    b.buf = append(b.buf, OpLocalSet)
    b.buf = AppendULEB128(b.buf, arrLocal)

    // save idx (int arrives as i64 → unwrap to i32)
    if err := b.walk(n.Args[0]); err != nil { return err }
    b.buf = append(b.buf, OpI32WrapI64, OpLocalSet)
    b.buf = AppendULEB128(b.buf, idxLocal)

    // save elem to return: arr + 4 + idx*eSize
    b.buf = append(b.buf, OpLocalGet); b.buf = AppendULEB128(b.buf, arrLocal)
    b.buf = append(b.buf, OpI32Const, 4, OpI32Add)
    b.buf = append(b.buf, OpLocalGet); b.buf = AppendULEB128(b.buf, idxLocal)
    b.buf = append(b.buf, OpI32Const); b.buf = AppendULEB128(b.buf, eSize)
    b.buf = append(b.buf, OpI32Mul, OpI32Add)
    b.buf = append(b.buf, loadOp); b.buf = AppendULEB128(b.buf, loadAlign); b.buf = AppendULEB128(b.buf, 0)
    b.buf = append(b.buf, OpLocalSet); b.buf = AppendULEB128(b.buf, retLocal)

    // new_len = old_len - 1
    b.buf = append(b.buf, OpLocalGet); b.buf = AppendULEB128(b.buf, arrLocal)
    b.buf = append(b.buf, OpI32Load);  b.buf = AppendULEB128(b.buf, 2); b.buf = AppendULEB128(b.buf, 0)
    b.buf = append(b.buf, OpI32Const, 1, OpI32Sub)
    b.buf = append(b.buf, OpLocalSet); b.buf = AppendULEB128(b.buf, lenLocal)

    // cur = idx
    b.buf = append(b.buf, OpLocalGet); b.buf = AppendULEB128(b.buf, idxLocal)
    b.buf = append(b.buf, OpLocalSet); b.buf = AppendULEB128(b.buf, curLocal)

    // internal shift loop — NOT on loopStack
    b.buf = append(b.buf, OpBlock, BlockTypeEmpty)
    b.blockDepth++
    blockMark := uint32(b.blockDepth)
    b.buf = append(b.buf, OpLoop, BlockTypeEmpty)
    b.blockDepth++
    loopMark := uint32(b.blockDepth)

    // exit: cur >= len → br_if out of block
    b.buf = append(b.buf, OpLocalGet); b.buf = AppendULEB128(b.buf, curLocal)
    b.buf = append(b.buf, OpLocalGet); b.buf = AppendULEB128(b.buf, lenLocal)
    b.buf = append(b.buf, OpI32GeS, OpBrIf)
    b.buf = AppendULEB128(b.buf, uint32(b.blockDepth)-blockMark)

    // dst: arr + 4 + cur*eSize
    b.buf = append(b.buf, OpLocalGet); b.buf = AppendULEB128(b.buf, arrLocal)
    b.buf = append(b.buf, OpI32Const, 4, OpI32Add)
    b.buf = append(b.buf, OpLocalGet); b.buf = AppendULEB128(b.buf, curLocal)
    b.buf = append(b.buf, OpI32Const); b.buf = AppendULEB128(b.buf, eSize)
    b.buf = append(b.buf, OpI32Mul, OpI32Add)

    // src: arr + 4 + (cur+1)*eSize
    b.buf = append(b.buf, OpLocalGet); b.buf = AppendULEB128(b.buf, arrLocal)
    b.buf = append(b.buf, OpI32Const, 4, OpI32Add)
    b.buf = append(b.buf, OpLocalGet); b.buf = AppendULEB128(b.buf, curLocal)
    b.buf = append(b.buf, OpI32Const, 1, OpI32Add)
    b.buf = append(b.buf, OpI32Const); b.buf = AppendULEB128(b.buf, eSize)
    b.buf = append(b.buf, OpI32Mul, OpI32Add)
    b.buf = append(b.buf, loadOp); b.buf = AppendULEB128(b.buf, loadAlign); b.buf = AppendULEB128(b.buf, 0)

    // store dst ← src
    b.buf = append(b.buf, stOp); b.buf = AppendULEB128(b.buf, uint32(stAlign)); b.buf = AppendULEB128(b.buf, 0)

    // cur++
    b.buf = append(b.buf, OpLocalGet); b.buf = AppendULEB128(b.buf, curLocal)
    b.buf = append(b.buf, OpI32Const, 1, OpI32Add)
    b.buf = append(b.buf, OpLocalSet); b.buf = AppendULEB128(b.buf, curLocal)

    // continue loop
    b.buf = append(b.buf, OpBr)
    b.buf = AppendULEB128(b.buf, uint32(b.blockDepth)-loopMark)

    b.blockDepth -= 2
    b.buf = append(b.buf, OpEnd, OpEnd)

    // write new length
    b.buf = append(b.buf, OpLocalGet); b.buf = AppendULEB128(b.buf, arrLocal)
    b.buf = append(b.buf, OpLocalGet); b.buf = AppendULEB128(b.buf, lenLocal)
    b.buf = append(b.buf, OpI32Store); b.buf = AppendULEB128(b.buf, 2); b.buf = AppendULEB128(b.buf, 0)

    // return removed element
    b.buf = append(b.buf, OpLocalGet); b.buf = AppendULEB128(b.buf, retLocal)
    return nil

func TestEndToEnd_ArrayRemove(t *testing.T) {
    src := `
        fn remove_middle(): int {
            let arr: int[] = [10, 20, 30];
            let r = arr.remove(1);
            return r;
        }
        fn remove_shifts(): int {
            let arr: int[] = [10, 20, 30];
            arr.remove(0);
            return arr[0];
        }
        fn remove_len(): int {
            let arr: int[] = [10, 20, 30];
            arr.remove(2);
            return arr.len();
        }
    `
    runOne(t, src, "remove_middle", nil, 20)   // returns the element
    runOne(t, src, "remove_shifts", nil, 20)   // arr[0] becomes 20 after remove(0)
    runOne(t, src, "remove_len",   nil, 2)    // length decremented
}
